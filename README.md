# game-common

游戏项目的公共能力库。

这个仓库应该保持独立、可版本化，并被多个游戏项目以明确的版本依赖。它不应该依赖任何具体游戏。

## 目标

- 提供与具体游戏无关的基础能力
- 通过稳定 API 被不同游戏复用
- 使用 tag 和语义化版本发布
- 保持核心层与具体引擎、平台和服务解耦

## 目录结构

```text
.
├── src/
│   ├── core/          # 生命周期、配置、结果类型等基础抽象
│   ├── storage/       # 存档、缓存和数据持久化抽象
│   ├── networking/    # 网络请求、重试和连接状态抽象
│   ├── publishing/    # 构建、版本和发布相关能力
│   ├── utils/         # 小型、通用、无业务的工具函数
│   └── adapters/      # 引擎、平台或服务适配层
├── tests/             # 公共能力测试
├── docs/              # API 和架构文档
├── AGENTS.md
└── CHANGELOG.md
```

## 使用原则

游戏项目应依赖已经发布的版本，例如：

```text
game-a -> game-common v0.1.0
game-b -> game-common v0.1.0
```

公共仓库的 breaking change 应升级主版本号，并在 `CHANGELOG.md` 中说明迁移方式。

## 当前状态

这是公共能力库的初始骨架，具体实现和引擎适配层会根据第一个接入的游戏逐步增加。

发布到公开平台前，请补充许可证、贡献指南和安全披露方式。
